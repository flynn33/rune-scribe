# Candidate Identifier Application Manual

- Put each exact accessibility identifier on the smallest complete visual wrapper named by the catalog.
- A screen ID belongs on the complete navigable application surface, excluding system-owned chrome.
- `theme.artifact-preview.<relicID>` belongs on the complete composed Relic, Script, Seal, Frame, and background canvas—not its surrounding controls.
- Picker-container IDs belong on the complete provider-neutral grid or list. Every Relic and Seal tile also carries its exact Artifact ID.
- Vault-state IDs belong on the complete Codex card wrapper after the deterministic fixture applies the named state.
- Mastery IDs belong separately on the full mastery panel, Frame visual, and Crest visual.
- Renderer-output IDs identify deterministic PNG exports from production renderers.
- Existing IDs may remain as compatibility aliases.
- Missing IDs must be added and the narrow gate rerun. Do not request operator mapping input.
