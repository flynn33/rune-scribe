# Controlling Decision — Historical Evidence Boundary

Historical evidence is immutable evidence of its own source and instruction generation. It must not be rewritten to claim qualification of later source.

## Preserve

- prior Norse visual-remediation evidence;
- remediation-v1 evidence;
- earlier hardening and qualification reports;
- their original source SHAs, commands, results, and limitations.

## Create

All Theme Fidelity v4 acceptance evidence belongs under a new directory equivalent to:

`docs/verification/theme-fidelity-v4/`

Every v4 result must bind to the final proposed branch head and the v4.1 comparison-authority hash. Existing historical test suites may be rerun, but new results must be written into the v4 evidence tree rather than replacing historical records.

A repository checker that previously demanded one global “latest evidence” file must be corrected to validate evidence by generation and controlling package.
