## Approved target outcome

APPROVAL-PIVOT-001 establishes free Norse and all retained tools; one one-time **$1.99 purchase** for the complete first **Elven Series** (Moonleaf, Sunspire, Wildwood and Gloamthorn), with every included item usable immediately; first-series inclusion for original paid-app owners; and removal of active achievements and Game Center. The four provider modules remain separate. Preserve user data, valid selections and free reading/decoding of incoming themed messages.

This is the approved future outcome. Current 1.0.47 source still has its existing progression and Game Center behavior. No purchase product, eligibility cutoff, production migration policy, cross-platform relationship or Family Sharing arrangement is selected by publishing these reports.

## Findings to carry into technical review

The inventory accounts for **all 84 historical catalog IDs**, **156 item rows**, **315 physical resource entries**, four embedded localizations and 14 Norse compatibility aliases. Nine textual titles are shipped state/content; five shared visual IDs explicitly defer artwork. All existing mastery/encounter visuals remain within the approved content promise.

Both Codex and artifact ownership consumers need replacement. Preserve runtime capability/lifecycle/resource validation and the free inbound path. Before retiring earning, preserve cipher-library v2 compatibility, share-terminal recovery and relationship/key-delivery invariants. Game Center retirement must prevent persisted opt-in/queues and relaunch/retry wakes from resuming work. Review selected-Codex preference synchronization separately from progression-only cloud activity.

Migration mechanisms and their tests remain proposals. The authoritative Project Record route, historic adopted method binding, reviewed realization contracts and actual paid/free Store history remain unresolved. The next eligible operation is reconciliation of the existing record and binding, followed by reviewed technical contracts before a separately authorized implementation assignment.
